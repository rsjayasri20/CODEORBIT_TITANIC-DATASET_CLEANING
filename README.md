# Titanic Data Cleaning and Analysis

## 1. Project Title

**Titanic Dataset Cleaning Using Python and Pandas**

This project focuses on cleaning the Titanic dataset by handling missing values, checking duplicate records, correcting data types, and performing basic statistical analysis.
## Dataset Description

## 2. Dataset Description

* **Dataset Name:** `Titanic-Dataset.csv`
* **Passenger Details:** Passenger ID, name, age, and gender.
* **Survival Information:** Survival status (0 = Did not survive, 1 = Survived).
* **Ticket Class:** Passenger class (1st, 2nd, or 3rd class).
* **Family Information:** Number of siblings/spouses (`SibSp`) and parents/children (`Parch`) aboard.
* **Travel Details:** Ticket number, fare, cabin, and port of embarkation (`Embarked`).
* **Missing Values:** Some columns, such as `Age`, `Cabin`, and `Embarked`, may contain missing values.
* **Purpose:** To clean the dataset, handle missing values, check duplicates, correct data types, and perform basic statistical analysis.
**Dataset Source:** Kaggle — Titanic Dataset
https://www.kaggle.com/competitions/titanic/data

## 4. Setup Instructions

1. Download or clone this repository to your computer.
2. Open the `code_orbit1.ipynb` notebook in Google Colab.
3. Download the original Titanic dataset (`Titanic-Dataset.csv`).
4. Upload `Titanic-Dataset.csv` when prompted by the notebook.
5. Run all the code cells in order.
6. Review the data-cleaning results and statistical analysis.
7. The cleaned dataset will be saved as `cleaned_titanic.csv`.
